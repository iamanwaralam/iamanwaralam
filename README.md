## About me

I'm a full-stack web developer in Dubai with a background across web and mobile development. I build **Next.js, React, Shopify, and WordPress** websites and e-commerce platforms, and combine development with **technical SEO, analytics, and web infrastructure** management.

- Rebuilt [akiuae.com](https://akiuae.com) from the ground up in Next.js, **35% faster** on Google's page-speed measures
- Led a **zero-downtime** DNS and hosting migration while keeping Microsoft 365 email running without interruption
- Run the [Esthica](https://esthica.com) Shopify store and built a **Next.js headless storefront** for [Beatryx](https://beatryx.com)
- Latest products I've built and shipped: **[Netcurb](#featured-products)**, **[LetsEditPDF](#featured-products)**, and **[Dualfon](#featured-products)**
- Started in Android and Flutter, and still ship my own apps in **Kotlin Multiplatform** and Jetpack Compose
- Early adopter of AI-assisted engineering with **Claude Code** and **MCP** connectors for GitHub, Figma, and deployment tools
